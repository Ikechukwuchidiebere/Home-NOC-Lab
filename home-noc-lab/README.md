# home-noc-lab

A home network operations centre (NOC) lab, built to practise the day-to-day work of a NOC technician: monitoring, troubleshooting, incident response, change management and documentation.

**Author:** Ikechukwu Emmanuel Chidiebere.

## Labs

| # | Lab | Skills | Status |
| --- | --- | --- | --- |
| 01 | [Linux server networking and troubleshooting fingerprints](lab-01-linux-networking-and-troubleshooting.md) | Ubuntu Server, SSH, `ip`/`ss`, Wireshark, OSI troubleshooting | Complete |
| 02 | VLANs and inter-VLAN routing (Cisco Packet Tracer) | Switching, VLANs, trunks, routing | Next |
| 03 | Dual-ISP BGP failover | BGP, routing, failover | Planned |
| 04 | Mini NOC monitoring (Zabbix + Grafana) | SNMP, monitoring, alerting | Planned |
| 05 | Redundant DNS and break-fix | DNS, Linux services, logs | Planned |
| 06 | Disk and service watchdog script | Bash, automation | Planned |
| 07 | Brute-force detection and response | fail2ban, SIEM, incident response | Planned |
| 08 | Change window drill | Change management, config backup | Planned |
| 09 | Certificate expiry checker | TLS, Python | Planned |
| 10 | Ticketing, RCAs and shift handover | ITIL, documentation | Planned |

## Lab environment

- HP EliteBook 840 G5, 20 GB RAM, Windows 11 Pro
- VMware Workstation Pro, Ubuntu Server 24.04 LTS VMs
- Cisco Packet Tracer, Wireshark
